Map label glyphs (MapLibre SDF glyph ranges), bundled so map text needs no font server.

NotoSans-Bold/0-255.pbf and 256-511.pbf: Noto Sans Bold, Latin and Latin Extended-A, as built by
openmaptiles/fonts release v2.0 (noto-sans.zip, https://github.com/openmaptiles/fonts/releases/tag/v2.0),
copied unchanged. The directory is named without spaces because MapLibre puts the font stack name in
the asset path. Other ranges are not bundled: map labels are line numbers and stop names in Latin
script.
